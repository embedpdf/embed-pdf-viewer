# @embedpdf/web

The browser code EmbedPDF's framework packages share: gestures, cursors, the clipboard, file dialogs and printing.

Part of [EmbedPDF](https://www.embedpdf.com). It comes with `@embedpdf/angular`, `@embedpdf/react`, `@embedpdf/svelte`, `@embedpdf/viewer`, `@embedpdf/vue`.

## Documentation

- [Headless](https://www.embedpdf.com/docs/headless): Build your own PDF viewer from plugins, components and hooks, in React, Vue, Svelte or Angular.
