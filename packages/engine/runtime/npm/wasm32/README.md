# @embedpdf/engine-runtime-wasm32

Platform package for `@embedpdf/engine-runtime`. Install `@embedpdf/engine-runtime` instead of depending on this package directly.

Ships the engine as `embedpdf.wasm` plus environment-split JS glue (`embedpdf.browser.js`, `embedpdf.node.js`, `embedpdf.node.cjs`). Derived from PDFium; not affiliated with or endorsed by Google.
