# @embedpdf/engine-runtime-wasm32

The EmbedPDF engine's PDF runtime as WebAssembly, for browsers, and for Node where no native build fits.

Part of [EmbedPDF](https://www.embedpdf.com). It comes with `@embedpdf/engine`, `@cloudpdf/engine`, `@cloudpdf/server`.
