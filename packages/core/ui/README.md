# @embedpdf/core-ui

Toolbar logic for EmbedPDF: fits items into the space there is, moves the rest to a menu, and reads keyboard shortcuts. No DOM.

Part of [EmbedPDF](https://www.embedpdf.com). It comes with `@embedpdf/angular`, `@embedpdf/react`, `@embedpdf/svelte`, `@embedpdf/viewer`, `@embedpdf/vue`.

## Documentation

- [Toolbar](https://www.embedpdf.com/docs/headless/ui/toolbar): A toolbar that fits itself to the space it has, shrinking buttons and moving them into a menu instead of wrapping, with every pixel yours.
