# @embedpdf/core-text

Lays text out as the EmbedPDF engine does: the font of each character, right-to-left order, and a form field's lines. No DOM.

Part of [EmbedPDF](https://www.embedpdf.com). It comes with `@embedpdf/angular`, `@embedpdf/react`, `@embedpdf/svelte`, `@embedpdf/viewer`, `@embedpdf/vue`.

## Documentation

- [Fonts](https://www.embedpdf.com/docs/headless/documents/fonts): List the fonts a document can be written in, see what each one allows, and draw text in a browser in the font the engine writes it with.
