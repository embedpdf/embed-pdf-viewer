# @embedpdf/core-stage

The layout and the camera of EmbedPDF's Stage: where the pages are, and which part of them is in view. No DOM.

Part of [EmbedPDF](https://www.embedpdf.com). It comes with `@embedpdf/angular`, `@embedpdf/react`, `@embedpdf/svelte`, `@embedpdf/viewer`, `@embedpdf/vue`, `@cloudpdf/plugin-protected-display`.

## Documentation

- [Scroll, zoom & layout](https://www.embedpdf.com/docs/headless/viewing/stage): Show the pages with the Stage, and control zoom, layouts, page navigation, touch and view rotation.
