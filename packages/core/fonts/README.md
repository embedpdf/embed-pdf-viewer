# @embedpdf/core-fonts

The 14 standard PDF fonts as the EmbedPDF engine draws them: font files a browser can load, and the measures the engine lays text out with.

Part of [EmbedPDF](https://www.embedpdf.com). It comes with `@embedpdf/angular`, `@embedpdf/engine`, `@embedpdf/react`, `@embedpdf/svelte`, `@embedpdf/viewer`, `@embedpdf/vue`, `@cloudpdf/engine`, `@cloudpdf/server`.

## Documentation

- [Fonts](https://www.embedpdf.com/docs/engine/documents/fonts): Write text in any font and any language, use the fonts a document already has, and show typed text in a browser exactly as the engine will draw it.
