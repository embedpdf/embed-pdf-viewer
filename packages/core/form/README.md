# @embedpdf/core-form

Draws PDF form fields for EmbedPDF as the engine draws them. No DOM.

Part of [EmbedPDF](https://www.embedpdf.com). It comes with `@embedpdf/angular`, `@embedpdf/react`, `@embedpdf/svelte`, `@embedpdf/viewer`, `@embedpdf/vue`.

## Documentation

- [Filling forms](https://www.embedpdf.com/docs/headless/forms): Let people fill in PDF forms, read and set values from your code, check required fields, and move form data in and out.
