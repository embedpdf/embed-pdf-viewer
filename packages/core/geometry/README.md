# @embedpdf/core-geometry

Points, sizes, boxes and page rotation for EmbedPDF, with the transforms between a page, the view and the screen. No dependencies, no DOM.

Part of [EmbedPDF](https://www.embedpdf.com). It comes with `@embedpdf/angular`, `@embedpdf/react`, `@embedpdf/svelte`, `@embedpdf/viewer`, `@embedpdf/vue`, `@cloudpdf/plugin-protected-display`.

## Documentation

- [Coordinates](https://www.embedpdf.com/docs/headless/concepts/coordinates): EmbedPDF has one way to say where something is: points from the page's top-left corner, y going down. Pixels only come in when you draw.
