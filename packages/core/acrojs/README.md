# @embedpdf/core-acrojs

The Acrobat JavaScript a PDF's scripts expect, for EmbedPDF: its objects, its security rules and the code a sandbox starts with.

Part of [EmbedPDF](https://www.embedpdf.com). It comes with `@embedpdf/angular`, `@embedpdf/react`, `@embedpdf/svelte`, `@embedpdf/viewer`, `@embedpdf/vue`, `@cloudpdf/plugin-protected-display`.

## Documentation

- [Actions & scripts](https://www.embedpdf.com/docs/headless/documents/actions): Decide what a PDF may do by itself: links, buttons, form calculations, JavaScript, opening websites and printing.
