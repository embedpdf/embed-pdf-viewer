# @embedpdf/viewer-chrome

The interface of the EmbedPDF viewer as one React component: its toolbars, panels, document tabs and theme.

Part of [EmbedPDF](https://www.embedpdf.com). It comes with `@embedpdf/viewer`.

## Documentation

- [Viewer](https://www.embedpdf.com/docs/viewer): A complete PDF viewer you add with one tag, then make your own with a few lines of config, in plain HTML, React, Vue, Svelte or Angular.
