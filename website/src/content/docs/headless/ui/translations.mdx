them while the app runs. Register it with the user's language:

`negotiateLocale` picks the best language you have for what the browser asks, such as `nl` for a
browser set to `nl-BE`. A language in `loaders` is loaded the first time someone switches to it, so
your bundle carries only the one you start with.

## Strings

A language's `translations` are your strings, grouped however you like:

```ts
export default {
  toolbar: { save: 'Opslaan', zoomIn: 'Inzoomen' },
  search: {
    results: { one: '{count} resultaat', other: '{count} resultaten' },
  },
};
```

```ts
t('toolbar.save'); // 'Opslaan'
t('search.results', { params: { count: 3 } }); // '3 resultaten'
```

<Fw only="angular">In a template, the pipe takes the same options: `{{ 'search.results' | epdfT: { params: { count: 3 } } }}`.</Fw>

- **`{name}`** is filled in from `params`.
- **Plurals**: a string with `one` and `other` picks by `params.count`.
- **Missing strings** fall back to the fallback language (English unless you set another), then to
  `fallback` if you pass one, then to the key itself. You get a warning in the console once, so you
  notice.

## Add strings later

For a plugin of your own, or strings from your server, add them to a language while the app runs:

```ts
i18n.addTranslations('nl', { review: { approve: 'Goedkeuren' } });
i18n.addTranslations('nl', { 'review.reject': 'Afwijzen' }); // a dotted key works too
```

`registerLocale()` adds a whole new language, and returns a function that removes it again.

## EmbedPDF's own text

Commands have labels, and the [standard commands](commands#the-standard-commands) come translated in
English, Dutch, German, French, Spanish, Chinese, Swedish and Japanese, the languages of the standard
stamps. Change any of them with `addTranslations`, under the same keys.

## Methods

Everything `useI18n()` gives you.

| Method                              | What it does                                                                                                                                  |
| :---------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------------------- |
| `t(key, { params?, fallback? })`    | A string in the current language, with `params` filled in. <Fw only={['react', 'vue', 'svelte']}>In a component, use `useT()`, which <Word of="rerenders" /> when the language changes.</Fw><Fw only="angular">In a template, use the `epdfT` pipe, which updates when the language changes.</Fw> [Strings](#strings) |
| `getTranslator()`                   | A `t` function that stays the same until the language or the strings change, for code that caches on it.<Fw only={['react', 'vue', 'svelte']}> `useT()` returns it.</Fw>                 |
| `hasKey(key)`                       | Whether a key has a string in the current or the fallback language. Never warns.                                                              |
| `setLocale(code)`                   | Loads the language if it needs to, then switches. Resolves once it shows; rejects when it can't load, or when a newer call replaces it. [Switch the language](#switch-the-language) |
| `addTranslations(code, translations)` | Adds strings to one of your languages, loaded or not, and replaces the ones with the same key. [Add strings later](#add-strings-later)        |
| `registerLocale(locale)`            | Adds a whole language, `{ code, name, direction?, translations }`, and returns a function that removes it again                                     |
| `getSettings()`, `updateSettings(changes)`, `resetSettings()` | Reads the settings, changes them while the app runs, or goes back to what you registered. In a component, use `useI18nSettings()`. [Settings](#settings) |

Every method that returns a promise also takes a `signal` in its options, to cancel it.

## State

| Field       | What it is                                                                                          | Read once            |
| :---------- | :-------------------------------------------------------------------------------------------------- | :------------------- |
| `locale`    | The current language's code                                                                         | `getLocale()`        |
| `direction` | `'ltr'` or `'rtl'`, how the current language reads                                                  | `getDirection()`     |
| `locales`   | Every language you can switch to, loaded or not, each with `code`, `name`, `direction` and `loaded`. A language in `loaders` shows its code as its `name` until it's loaded. | `listLocales()` |
| `loading`   | The code of the language being loaded, or `null`                                                    | `getLoadingLocale()` |

## Settings

Set them when you register the plugin, and change them while the app runs with
`i18n.updateSettings({ … })`; `i18n.resetSettings()` goes back to what you registered, and
`useI18nSettings()` gives you the current settings.

| Setting          | What it does                                               | Default          |
| :--------------- | :--------------------------------------------------------- | :--------------- |
| `locale`         | The language to start with                                 | `fallbackLocale` |
| `fallbackLocale` | The language to use for strings another language misses    | `'en'`           |
| `locales`        | Languages loaded from the start                            | none             |
| `loaders`        | Languages loaded when someone switches to them             | none             |

## Good to know

### Before a document opens

The plugin needs no engine and no document, so your loading screen, a password prompt and an empty
viewer can be translated too.

### A language that fails to load

When a language in `loaders` can't be loaded, for example because the user is offline, the viewer
stays in the language it had, and <Fw only={['react', 'vue', 'svelte']}>`onLocaleLoadFailed`</Fw><Fw only="angular">`localeLoadFailed$`</Fw> tells you why. Call `setLocale()` again to
try once more.
