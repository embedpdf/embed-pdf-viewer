# Panels & dialogs

A viewer has sidebars (thumbnails, comments, search), dialogs and menus. The shell plugin keeps track of
which are open, so a toolbar button, a keyboard shortcut and your own code can all open the same
panel, and you can remember the layout for next time. You draw the panels; the plugin only holds their
state. Register `shellPlugin()`:

<Fw only="angular">

The `epdfPanelToggle` directive toggles the panel from your own button, with `epdfPanelToggleExclusive`
for its [group](#one-panel-per-side), and sets the button's `aria-expanded`.

</Fw>

The names are yours: `'comments'`, `'thumbnails'`, `'settings'`. Each document keeps its own, so every
tab remembers which panels were open.

## One panel per side

Most layouts show one panel per side. Give panels a group with `exclusive`, and opening one closes the
others in that group:

```ts
shell.open('thumbnails', { exclusive: 'left' });
shell.open('outline', { exclusive: 'left' }); // closes thumbnails
shell.open('comments', { exclusive: 'right' }); // the left panel stays
```

## Open a panel with something in it

A panel can carry data, such as which comment to scroll to:

```ts
shell.open('comments', { exclusive: 'right', props: { focus: thread.root.ref } });
```

## From commands

A [command](commands) can open a panel with no code: give it `panel`, and its button toggles the panel
and shows as pressed while it's open:

```ts
{ id: 'panel:comments', label: 'Comments', icon: 'comment', panel: { id: 'comments', exclusive: 'right' } }
```

`modal` does the same for a dialog, and `menu` for a menu.

## Menus

Menus are tracked separately, since several can be open at once, such as a menu and its submenu:

```ts
shell.openMenu('more');
shell.closeAllMenus(); // for a click outside, or Escape
```

`openMenus` in [State](#state) lists the open menus, the last one opened on top.

## Remember the layout

```ts
localStorage.setItem('panels', JSON.stringify(shell.getSnapshot()));

// next time
shell.applySnapshot(JSON.parse(localStorage.getItem('panels')!));
```

## Methods

Everything `useShell()` gives you.

| Method                                              | What it does                                                                                                                              |
| :-------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------- |
| `open(id, { exclusive?, props? })`                  | Opens a panel or dialog. `exclusive` closes the others in that group, and `props` travels with it. [One panel per side](#one-panel-per-side) |
| `toggle(id, { exclusive?, props? })`                | Opens a closed panel, or closes an open one                                                                                               |
| `close(id)`, `closeAll()`                           | Closes one panel, or every panel                                                                                                          |
| `updateSurfaceProps(id, props)`                     | Changes a panel's `props` without reopening it. [Open a panel with something in it](#open-a-panel-with-something-in-it)                   |
| `openMenu(id)`, `closeMenu(id)`, `toggleMenu(id)`   | Opens, closes or toggles one menu. Opening a menu leaves the others open, so a submenu stays above its menu. [Menus](#menus)              |
| `closeAllMenus()`                                   | Closes every menu, for a click outside or Escape                                                                                          |
| `getSnapshot()`, `applySnapshot(snapshot)`          | Everything the plugin holds, as plain data you can store; and back. [Remember the layout](#remember-the-layout)                           |

<Fw only={['react', 'vue', 'svelte']}>In a component, `useSurface(id)` gives you one panel: `{ isOpen, props, open, close, toggle }`.</Fw><Fw only="angular">In a component, `shell.surface(id)` gives you one panel: `isOpen()` and `props()` as signals, and `open()`, `close()` and `toggle()`.</Fw>

## State

<StateIntro hook="useShellState()" />

| Field          | What it is                                                                   | Read once                                                      |
| :------------- | :--------------------------------------------------------------------------- | :------------------------------------------------------------- |
| `openSurfaces` | The open panels and dialogs, each with its `id`, `exclusive` group and `props` | `listOpenSurfaces()`, or `isOpen(id)` and `getSurface(id)` for one |
| `openMenus`    | The open menus' ids, the last one opened on top                              | `listOpenMenus()`, or `isMenuOpen(id)` for one                 |

## Good to know

### No document yet

The panel <Word of="hooks" /> work before a document is open: every panel reads as closed, and opening one does
nothing until there is a document. So a toolbar outside `<DocumentGate>` can use them.
