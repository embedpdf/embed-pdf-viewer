# Angular Drop-in Viewer

The `@embedpdf/angular-pdf-viewer` package gives Angular applications a clean, standalone wrapper around the EmbedPDF viewer.

It is the best choice when you want a fully featured PDF viewer in Angular without building the shell, toolbar, and sidebar yourself.

## What you get

- **Standalone component API** — import `PDFViewer` directly into Angular components.
- **Provider-based defaults** — set a shared config once and override per usage.
- **Strong typing** — `PDFViewerConfig`, viewer events, and registry access are fully typed.
- **Runtime extensibility** — respond to `(ready)` and customize commands, theme, and UI schema.

## When to use it

Choose the Angular drop-in viewer if:

- you want a production-ready viewer quickly,
- you prefer Angular-native composition over imperative setup calls,
- you want shared defaults via Angular providers,
- and you still want runtime access to the underlying EmbedPDF registry.

Ready to wire it up? Head to [Getting Started](/docs/angular/viewer/getting-started).
