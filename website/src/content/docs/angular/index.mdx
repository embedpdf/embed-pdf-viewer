# Angular PDF Viewer

Angular support is now available through `@embedpdf/angular-pdf-viewer`.

The Angular package wraps the EmbedPDF viewer in a standalone component that feels natural in modern Angular apps, including provider-based defaults and zoneless bootstrap support.

## What ships today?

- **Standalone Angular component** — import `PDFViewer` directly into your component.
- **Provider defaults** — share app-wide defaults via `provideEmbedPdfViewerDefaults(...)` and override them locally with `provideEmbedPdfViewerConfig(...)`.
- **Runtime hooks** — respond to `(init)`, `(ready)`, and `(themechange)`.
- **Angular-first theming** — define viewer defaults in one place and override per instance.

## Recommended route

If you want the quickest, most reliable setup, start with the [Drop-in Viewer](/docs/angular/viewer/getting-started).
