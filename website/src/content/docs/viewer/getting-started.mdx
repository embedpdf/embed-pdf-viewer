# Getting Started

The ready-made viewer drops into any page — no build step required.

## Script tag

```html
<div id="pdf-viewer" style="height: 500px"></div>
<script async type="module">
  import EmbedPDF from 'https://cdn.jsdelivr.net/npm/@embedpdf/snippet@2/dist/embedpdf.js';

  EmbedPDF.init({
    type: 'container',
    target: document.getElementById('pdf-viewer'),
    src: 'https://snippet.embedpdf.com/ebook.pdf',
  });
</script>
```

## Package managers

```sh npm2yarn
npm install @embedpdf/snippet
```
