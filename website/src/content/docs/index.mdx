# EmbedPDF Documentation

Two ways to integrate, one engine underneath.

- **[Viewer](/docs/viewer/getting-started)** — the drop-in PDF viewer. A few
  lines of code, a full toolbar, works with any stack.
- **Headless** — build your own UI on the plugin system. _Arrives with the v3
  adapter docs._

## Quick taste

```sh npm2yarn
npm install @embedpdf/snippet
```
