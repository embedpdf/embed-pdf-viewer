Touch gesture engine: native-feeling touch input for the Stage. One shared controller (`@embedpdf/web`) synthesizes the physics the platform scroller normally supplies — momentum fling on release (UIScrollView's deceleration curve, catchable mid-flight), pointer-tracked two-finger pinch anchored at the centroid, tap/double-tap-zoom/long-press classification — and arbitrates by modality: a finger navigates first (pan/pinch/fling under any tool, long-press hands to the hub as word-selection), while mouse and pen keep the tool-first routing unchanged. Safari `GestureEvent`s are demoted to desktop-trackpad-only so they no longer fight the pointer stream on iOS. The stage capability gains `beginGesture`/`endGesture` (one zoom-intent commit and one rest-settle per gesture instead of per event), `fling`, `cameraInMotion`, and `doubleTapZoom`; `PointerSample` gains `pointerType` and a `cancel` phase (with `onCancel` on handlers) so a second finger converts a tool gesture into a pinch without committing it; and `<SelectionHandles>` adds iOS-style draggable start/end handles for growing a touch selection — drawn the way the platform draws them: a caret bar forming the selection's own edge, spanning the boundary line's height (scaling with zoom), capped by a screen-constant circle above the first line / below the last. Annotation editing keeps working under touch through the consent ladder: `Tool.touchDirect` (drag-create draw/markup tools take single-finger touch wholesale, two fingers navigate) and `InteractionHandler.claimsTouch`/`wouldClaimTouch` (a selected annotation's body and its handles own the drags that start on them — unselected bodies keep scrolling, the Apple Markup convention), with finger-sized grab zones on touch and a revert-on-cancel so a second finger converts a half-moved annotation into a pinch without committing it. Review hardening: the draw and marquee handlers discard their draft on cancel (a pinch takeover can no longer commit a shape whose corner teleports to the second finger), body claims mirror the core's whole-selection `canMove` (a selected highlight/caret keeps scrolling instead of dead-zoning the drag), releases flush the last rAF-coalesced pan/pinch step, `doubleTapZoom` records its zoom intent up front so a caught animation never strands a stale fit intent, and the gesture controller gained a fake-DOM lifecycle test suite (tap/double-tap/long-press/claims/pinch handoff/flush/catch/detach). Phase 2: rubber-band overscroll — touch gestures are ELASTIC (`beginGesture({ elastic: true })`): pans past the clamp stretch on the iOS resistance curve, releases spring home critically damped, a fling reaching a content edge converts its remaining velocity into a bounce (one per-axis glide/spring law), and catching a mid-bounce stretch holds it under the finger. The clamp stays the untouched law of rest; mouse drags and wheel pans remain rigid, so desktop behavior is unchanged. Release polish: a pinch's identity persists through its release — the finger left over when the other lifts starts a DISARMED pan (it re-earns panning by crossing slop, so release-rolls neither pan nor fling) and any glide comes from the pinch's preserved CENTROID trail, sampled once per applied frame (per-event sampling zig-zagged between sequentially-reporting fingers and manufactured phantom velocity); and `doubleTapZoom` animates the INVARIANT instead of the coordinates — geometric zoom interpolation with the camera derived from the tapped anchor each frame, so the tapped point holds still by construction instead of swinging along the curved path that independent x/y/zoom lerps produce. Platform haptics: a workspace-scoped `feedbackPlugin`/`FeedbackToken` (in `@embedpdf/plugin-interaction`) carries ONE `PlatformFeedback` provider — the platform's own three-family vocabulary (`selection`/`impact`/`notify`, mirroring iOS's generator families) — consumed as an optional dependency; `@embedpdf/web` ships `vibrationFeedback` (Vibration API — Android buzzes, iOS Safari is a safe silent no-op until Apple ships a haptics API; the community switch-control hacks were evaluated and deliberately not shipped, as iOS 26.5 patched programmatic triggering) and `wkFeedback(handlerName)` for native shells; the viewer registers vibration feedback by default. `PointerSample` gains a first-class `gesture: 'long-press'` marker (replacing clickCount-sniffing), the selection handler fires the selection tick only when a touch long-press actually engages a word, `selectWordAt`/`selectLineAt` report success, and `beginTextEditAt` reports whether it opened a free-text — so a long-press on a non-text annotation now falls through to selecting it instead of being swallowed. Release identity is CHARACTER-gated: the controller keeps a per-frame pinch-span trail beside the centroid trail and lets a release glide only when centroid speed dominates span speed — a two-finger pan still glides, while a fast pinch ends still (the lifting finger's flick used to masquerade as centroid velocity and scroll the zoom). Overscroll obeys the platform rule that the rubber softens only the edges of a scroll RANGE: an axis whose content FITS the viewport has no travel and stays rigid — no stretch under a tug, no bounce from a fling (its release velocity is discarded) — so a fit-width page is immovable horizontally and a fully-visible page immovable entirely, exactly like a `UIScrollView` without `alwaysBounce*`. `doubleTapZoom` climbs the platform LADDER instead of a two-state toggle: ascending reading postures derived from zoom intents (automatic fit → fit-width → 2.5× the automatic fit), each tap moving to the next posture meaningfully above the current zoom and resetting past the top; stops within 10% collapse, so on phones (where automatic IS fit-width) the familiar toggle survives, while a zoomed-out view now restores fit-width first. Internally the stage's pure motion laws — the rubber curve pair, the glide/spring steppers, the tween interpolators — moved to a `motion.ts` sibling module (the `wheel.ts` convention) with direct property tests; the capability keeps only the impure drivers.
