'@embedpdf/svelte': minor

Add the Svelte bindings for stamps, measurements and redaction. `@embedpdf/svelte/stamp` has `useStamp()`, `useStampState()` (the armed stamp), `useStampSettings()` and `useStampEvent()`; `useStampLibraries(filter?)` and `useStampAssets(filter?)` are the libraries and their stamps as `{ current }` (pass the filter as a function to follow a prop: `useStampAssets(() => ({ libraryId }))`), and `useStampAssetPreviewUrl(assetId)` is an image URL for a stamp's preview, revoked when the preview changes or the component goes away. `indexedDbByteStore` keeps libraries in the browser between visits, with `persistStampLibraries` and `restoreStampLibraries`. `@embedpdf/svelte/measurement` has `useMeasurement()`, `useMeasurementState()`, `useMeasurementSettings()`, `useMeasurementEvent()`, `usePageScale(page)` (a page's scale, `null` for a `null` page) and `useMeasurementReadout(ref)` (a measurement's `{ kind, value, label }`), both `{ current }`. `@embedpdf/svelte/redaction` has `useRedaction()`, `useRedactionState()` (`pendingCount`, `applying`, `lastResult`), `useRedactionSettings()`, `useRedactionEvent()` and `usePendingRedactions(filter?)`, the marks waiting to be applied, or one page's. Each entry re-exports its plugin, so registration travels with the UI, and every reader works before a document opens.
