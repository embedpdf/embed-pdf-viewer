A named type for the state: `FormState`, what `formState` reads and `useFormState()` returns, the State table of the form page with a comment on each field. Published types now name it instead of spelling out its fields. The plugin's model, from `/internal`, is now `FormModel`, made by `initialFormModel()`, so `FormState` has one meaning.
