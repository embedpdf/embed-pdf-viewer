`usePageEdit()` is the page edit capability (was `usePageEditor()`). `useMetadata()` is the metadata capability, and `useMetadataState()` returns `metadata`, `custom` and `status`, takes a selector, and returns the empty state without a document; `useCustomMetadata()` is gone. `useActionsSettings()` returns the actions settings, with or without a document.
