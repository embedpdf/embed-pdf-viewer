The annotation contract, on the kernel's `create()` hook. The public read model is the page-space `Annotation` record (`ref`, `page`, `subtype`, `bounds`, `geometry`, `props`, `flags`, `contents`, `author`, `createdAt`, `modifiedAt`, `group`, `inReplyTo`, `authority`, `raw`), reference-stable per entry: `get`, `list(filter?)`, `listSelected`, with the engine records on `getRaw`/`listRaw`. New reads: `hitTestAt`, `getStatus`, `refresh`, `getCreationDraft`, `getEditingRef`, `listTools`/`getTool`, `getToolDefaults` (was `currentDefaults`), `listPropSpecs` (was `propsForTool`), `getSnapSettings`/`getChromeSettings`.

Writes are page space and awaitable: `update(ref, { bounds | geometry, props, flags, contents, richText })` (the engine patch is `updateRaw`), `updateMany`, `setRotation`/`rotateBy`, `setContents`/`setRichText` (resolve on the engine's confirmation), `createMany`, `createFromSelection(subtype)` (was `markupFromSelection`; also `'insert-text'`, `'replace-text'` and `'redact'`), `createAttachment`, `deleteMany`. Selection: `select` takes one or many refs, new `selectAll`/`selectInRect`, `clearSelection` (was `deselect`), `getSelectionAnchor` (page space; a view env is optional), and `updateSelection`/`updateSelectionFlags`/`deleteSelection` resolve with a `BatchResult`; `rotateSelectionBy(±90)`, `resetSelectionRotation`, `toggleTextFormat`, `finishCreationDraft` (resolves with the ref; covers ink), `endTextEdit` are awaitable. `setToolDefaults`/`updateSnapSettings`/`updateChromeSettings`; `setFilePickerProvider` returns its remover; `readAttachment` (was `downloadAttachment`); `links.get` (was `of`). Comments: `listThreads`, `getThread`, `setText`, `delete`, `deleteThread`, `getPermissions` (hydration moved to `getStatus`/`refresh`) plus `comments.onThreadChanged`. Events: `onCreated`/`onUpdated` carry `annotation` and `raw` (was `dto`); new `onResynced`, `onSelectionChanged`, `onDraftChanged`, `onEditingChanged`. Refusals are `PluginError`s (`permission-denied`, `not-found`, `invalid-input`, `unsupported`).

Host (`/contract/host`, which now also carries `previewBucket` and the handler priorities): `listPageItems`, `listTextItems`, `listChromeNodes`, `listLinkItems`, `getAppearanceEpoch`, `getBakeScale`, `renderAppearances`, `pdfToPageRect`, `getHydration`, `deliverRemoteEvent`, `getEditingId`, `draftContents`/`draftRichText` (the editor's debounced path; the public `setContents`/`setRichText` commit at once), `getCssFontFamily`, `getHitKind`, `getCursorAt`, `hoverGhostAt`, `getToolGhost`, `getArmedStampPreview`, `getStampArmEpoch`, `listResolvedTools`, `getResolvedTool`, `getToolSubtype`, `getBehaviorFor`; `onDraftCaptured` is an event hook. Removed: `selection()`, `ensurePage`, `rotateSelection90`, `getSelected`, `comments.hydration`/`rehydrate`. Deferred: `reorder` (needs an engine verb), `duplicate`. `LinkNavItem.rect` is `bounds`.

Internally the plugin is now one folder per concern (`services/`, `read/`, `write/`, `sync/`, `comments/`, `tools/`) assembled by `controller.ts`; `types.ts` is split into `contract.ts`, `host-contract.ts` and `model.ts`. For `/internal` consumers, `createAnnotationCapability` is `createAnnotationController` and `registerAnnotationEffects` is `subscribeDocumentEvents`. `ArmedStampPreview` is exported from `/contract` (it is part of the public `StampPreviewProvider` signature).
