'@embedpdf/svelte': minor
---

Add the Svelte 5 adapter's foundation, one entry point per feature. `@embedpdf/svelte/runtime` has `<Viewer>` (with `fallback` and `error` snippets and `onReady`), `<DocumentGate>` (with `fallback`, `locked` and `error` snippets), `<DocumentScope>`, the documents readers (`useDocuments()`, `useDocument()`, `useDocumentsState()`, `useDocumentsEvent()`, `usePageList()`, `useViewerSettings()`), the generic readers (`useCapability()`, `useSelector()`, `useKernelValue()`, `stateReader()`, `settingsReader()`) and the page context (`usePage()`). `@embedpdf/svelte/stage` has `<Stage>` (its content is drawn on each page, `{#snippet children(page)}` when it needs the page, plus `pageChrome` and `overlay` snippets) with `bind:page`, `bind:zoom` and `bind:tool`, `<StageScope>`, `<Scrollbar>` and `useStage()`, `useStageState()`, `useStageSettings()`, `useStageEvent()`, `useScrollMetrics()`. `@embedpdf/svelte/render` has `<RenderLayer>` and the render readers, `@embedpdf/svelte/interaction` has `<PagePointerSource>`, the interaction readers and `useToolCursor()`, and `@embedpdf/svelte/anchored` has `<Anchored>`. A plugin's state is a reactive object (`state.zoomLevel`) with one derived value per field, one value is `{ current }`, and `use<Plugin>()` returns a handle that always talks to the document in scope, whose reads (`canGoNext()`) update a template.
