The widget DOM-event door: `notifyWidgetEvent(key, ref, event)` dispatches widget `/AA` trees (hover through the shared coalescing pump with folded-model presence flags). `activateWidget` now submits synchronously through the dispatcher (`WidgetActivationResult` carries the per-step `ActionTriggerResult`), falling back to the legacy path only when no `/A` tree exists. Script UI effects gain the dispatch-`origin` axis (separate from the name-tree-boot `phase`), and a script print request without `doc.print` authority is withheld form-side with a `ui-effect-suppressed` diagnostic — the permission gate no provider can override.
