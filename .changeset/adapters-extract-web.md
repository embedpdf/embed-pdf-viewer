Add the framework-neutral parts of the page layers, so every framework adapter shares one implementation: page boxes and quads in a layer's pixels (`rectInPixels`, `quadInPixels`, `svgPoints`, `isUprightQuad`); an annotation scene as SVG element descriptions (`svgShapesOf`, `sceneViewBox`, `ghostOpacity`); the selection chrome's paint and pixels (`annotationChromePaint`, `chromeInPixels`); the free-text editor controller (`attachTextBoxEditor`, `textBoxStyleOf`, `textPlateInPixels`); renderer behaviors and drawing ownership (`registerRendererBehaviors`, `rendererBehaviorId`, `lookRendererFor`, `annotationDrawingOf`, `lookFrameOf`); object URLs for previews and baked appearances (`objectUrlOf`, `loadObjectUrl`, `loadAppearanceUrls`); comment threads with page positions (`enrichCommentThreads`); anchor equality (`samePageBounds`, `sameSelectionAnchor`, `sameAnnotationAnchor`, `sameCreationDraftAnchor`, `sameRotationAnchor`, `sameSelectionEndpoints`); form field colors, looks, widget events and editing policies (`formColorsOf`, `cssFontOf`, `textFieldStyleOf`, `listBoxStyleOf`, `bindWidgetEvents`, `pressToggle`, `createTextFieldEditor`, `createOptimisticSelection`); event isolation (`isolatePointerDown`, `isolateWheel`); link anchors (`linkHrefOf`, `navigableLinksOf`, `isModifiedClick`, `openExternalUri`); click detection (`createClickDetector`); a standalone page's projector (`clientPageProjector`); toolbar measuring (`createToolbarWidths`, `observeWidth`, `observeContentWidth`, `toolbarMeasureKey`); the default file prompt (`pickRequestedFile`); and the browser's part of the standard commands (`standardCommandsBrowser`).
