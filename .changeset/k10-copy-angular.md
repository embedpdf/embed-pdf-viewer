`epdfSelectionClipboard` on an element of yours (`<div tabindex="0" epdfSelectionClipboard>`), the same shape as `epdfCommandShortcuts`, copies only while focus is inside it, for a page with more than one viewer, as that directive does for the other keys. `<epdf-selection-clipboard />` still copies anywhere on the page. `EpdfSelectionClipboard` is now a directive serving both; import it as before.
