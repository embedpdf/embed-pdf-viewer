Follows the documents, interaction and stage contracts: `useDocuments` exposes `getActiveId`, `retry`, `rename`, `save`/`saveLayer`; new `useDocumentEvent`. Stage hooks read through `getSettings` and the page registry (`usePages().pageCount`, `usePageList().pages` come from `documents.listPages`); `useScrollMetrics`, `<Scrollbar>` and `<Stage>` bind the host lens. The actions adapter navigates with `goToPageIndex`. `SelectionLayer`, `SelectionMenu` and `SelectionHandles` follow the selection contract (`listSegments`, `getAnchor`, `isGestureActive`, `ensureLoaded`); the annotation-side anchor type is `AnnotationSelectionAnchor`. `RenderLayer` binds the render host lens: `renderSource`/`getSourceKey` for the base plane and a `ViewDemand` (`setDemand` in a layout effect, pure `getPlan`) for the tile plane. The annotation surface follows the annotation contract: `useAnnotationSelection` returns refs, `useAnnotationStatus` (was `useCommentsHydration`) returns a `ResourceStatus`, `useFilePickerProvider` uses the provider's remover, the menu anchors through `getSelectionAnchor`, and the text editor drafts through the host lens. The form surface follows the form contract: fill items address fields by `fieldRef`, `useFormField` resolves through `getFieldForWidget`, the fill layer binds the host lens (re-exported as `FormHostToken`). `LinkLayer` follows the link contract (`listLinks`, `ensureLoaded`, `getLabel`, the host `isNavigationEngaged`). The stamp hooks follow the stamp contract (`listLibraries`, `listAssets`, `getAssetPreview`).
