# @cloudpdf/admin-api

Shared CloudPDF admin HTTP contracts: the zod schemas and TypeScript types
for the admin API, used by both
[`@cloudpdf/server`](https://www.npmjs.com/package/@cloudpdf/server) (to
validate) and the
[`@cloudpdf/admin`](https://www.npmjs.com/package/@cloudpdf/admin) SDK (to
type requests and responses).

You normally don't install this directly — it arrives as a dependency of
those packages.
