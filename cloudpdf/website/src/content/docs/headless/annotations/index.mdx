# Annotations

Annotations are what people add on top of a page: highlights, sticky notes, shapes, stamps and
text boxes. The annotation plugin shows the ones a PDF already has, lets people draw and edit new
ones, and gives your code the same abilities. Every annotation is saved into the PDF, so it looks
the same in every other PDF app.

## Show the annotations in a PDF

Register `interactionPlugin()` and `annotationPlugin()`, then put an `<AnnotationLayer>` above the
rendered page:

```tsx
import { interactionPlugin } from '@embedpdf/react/interaction';
import { AnnotationLayer, annotationPlugin } from '@embedpdf/react/annotation';

const plugins = [stagePlugin(), renderPlugin(), interactionPlugin(), annotationPlugin()];

<Stage>
  {() => (
    <>
      <RenderLayer annotations={false} />
      <AnnotationLayer />
    </>
  )}
</Stage>;
```

`annotations={false}` tells the render layer to leave annotations out of the page picture. The
annotation layer draws them instead, so they can be selected, moved and changed.

`interactionPlugin()` is the shared input system. Every tool, from text selection to drawing,
speaks through it; see [Selecting & copying](text/selection) for how it works.

## Let people draw

A **tool** says what a click or a drag on the page creates. Activate one and people can draw:

```tsx
import { useInteraction, useInteractionState } from '@embedpdf/react/interaction';

function Toolbar() {
  const interaction = useInteraction();
  const { activeToolId } = useInteractionState();

  return ['pointer', 'square', 'ink', 'highlight', 'note'].map((id) => (
    <button key={id} aria-pressed={activeToolId === id} onClick={() => interaction.activateTool(id)}>
      {id}
    </button>
  ));
}
```

- **`pointer`** selects: click an annotation to select it, then move, resize or turn it.
- **`square`** draws a rectangle: drag, or just click for a default-size one.
- **`ink`** draws freehand.
- **`highlight`** highlights the text you select.
- **`note`** drops a sticky note where you click.

After you draw, the new annotation is selected and the tool stays active, so you can draw another.
You can change both; see [What happens after drawing](annotations/tools#what-happens-after-drawing).

## How it fits together

Everything on these pages is one of five things:

| Thing          | What it is                                                                         | Where you use it                           |
| :------------- | :--------------------------------------------------------------------------------- | :----------------------------------------- |
| **Annotation** | A record in the PDF: its kind, position, colors and text.                          | `useAnnotation().list()`                   |
| **Tool**       | What a click or drag creates, with which defaults, cursor and preview.             | `annotationPlugin({ tools })`              |
| **Layer**      | What each page draws: the annotations, the selection box and handles, the preview. | `<AnnotationLayer>`                        |
| **Overlay**    | Your own UI attached to an annotation, such as a menu or a hover card.             | `<AnnotationMenu>`                         |
| **API**        | Reading, creating, changing and deleting annotations, and listening for changes.   | `useAnnotation()`                          |

An annotation here is the same record the engine reads and writes: the same kinds, the same fields
and the same names. What you learn in the [engine's annotation pages](/docs/engine/annotations)
holds here too.

## The built-in tools

| Tool                                              | Makes                                       | How                                   |
| :------------------------------------------------ | :------------------------------------------ | :------------------------------------ |
| `square`, `circle`                                | A rectangle or an ellipse                   | Drag, or click for a default size     |
| `line`                                            | A line                                      | Drag, or click for a default length   |
| `polygon`, `polyline`                             | A closed or open shape of points            | Click each point, double-click to end |
| `ink`, `ink-highlight`                            | Freehand drawing, or a see-through marker   | Draw                                  |
| `free-text`, `free-text-callout`                  | A text box, or one with a line pointing out | Click or drag, then type              |
| `highlight`, `underline`, `strikeout`, `squiggly` | A mark over text                            | Select text                           |
| `insert-text`, `replace-text`                     | A suggested insertion or replacement        | Select text                           |
| `note`                                            | A sticky note                               | Click                                 |
| `stamp`                                           | An image or a PDF drawing                   | Click, then pick a file               |
| `attachment`                                      | A file pinned to a spot                     | Click, then pick a file               |
| `link`                                            | An area that opens a page or a website      | Drag                                  |

Measurement tools (`distance`, `perimeter`, `area`) and redaction (`redact`) are annotation tools
too. Their plugins add the rest of what they need.

You can change any tool, or add your own; see [Tools & defaults](annotations/tools).

## Who wrote it

Every annotation records who made it and who last changed it (`author`, `createdAt`,
`modifiedAt`). You don't set these on the annotation: they come from the user the document was
opened for.

<Engine local>

Tell the viewer who the user is, once. Every document it opens uses it:

```tsx
<Viewer
  engine={engine}
  plugins={plugins}
  identity={{ userId: 'u_381', displayName: 'Dana Smith' }}
  initialDocuments={[{ source: contract }]}
/>
```

`displayName` becomes the `author` other PDF apps show, and `userId` records who owns the
annotation. The same identity decides which annotations count as the user's own when
[permissions](concepts/permissions) say "only their own".

To open one document as someone else, give it its own `identity`. It replaces the viewer's for
that document:

```tsx
initialDocuments={[{ source: contract, identity: { userId: 'bot', displayName: 'Import job' } }]}
```

A document keeps the identity it was opened with. If you change the viewer's `identity`, documents
you open afterwards use the new one.

## Settings

Set them when you register the plugin. `snap`, `chrome` and `afterCreate` can change while the app
runs, with `annotation.updateSettings({ … })`; `annotation.resetSettings()` goes back to what you
registered, and `useAnnotationSettings()` gives you the current settings.

| Setting       | What it does                                                          | Page                                                        |
| :------------ | :-------------------------------------------------------------------- | :---------------------------------------------------------- |
| `tools`       | Change the built-in tools, or add your own                            | [Tools & defaults](annotations/tools)                       |
| `afterCreate` | Select a new annotation? Keep the tool active?                        | [What happens after drawing](annotations/tools#what-happens-after-drawing) |
| `chrome`      | The selection box, its handles and the rotation handle                | [Change the handles](annotations/selecting#change-the-handles) |
| `snap`        | Snapping to other annotations and to angles                           | [Snapping](annotations/selecting#snapping)                  |

Events are on [Events, saving & sharing](annotations/saving#events), and permissions on
[Annotations in code](annotations/with-code#permissions).
