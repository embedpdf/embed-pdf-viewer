# Plugins

Everything beyond the empty page is a plugin: you register the capabilities
your product needs and mount their layers inside your pages. Each plugin page
starts with a working example and covers the settings as you need them.

- **[Stage](./stage)** — lay out pages and handle pan, zoom, and page
  navigation. The view itself.
- **[Render](./render)** — draw crisp page bitmaps at every zoom without
  spending more memory than you allow. Deep-zoom tiles included.
- **[Selection](./selection)** — select text with the pointer or with code,
  read it, copy it, build a selection menu.

More plugin pages (annotations, forms, search) are on the way.
