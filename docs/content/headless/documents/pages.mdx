# Organizing pages

The page edit plugin changes the document's pages: rotate, reorder, delete, duplicate, and insert
new ones, blank or from another PDF. These are edits to the file, kept when it's downloaded. Register
`pageEditPlugin()` and use `usePageEdit()`:

<Example name="page-edit/organize" mode="open" />

```ts
const pageEdit = usePageEdit();

await pageEdit.rotateBy([page.ref], 90);
await pageEdit.move([page.ref], { index: 0 }); // to the front
await pageEdit.delete([page.ref]);
```

After an edit, everything that shows pages updates by itself: the Stage, thumbnails, page numbers. On
a shared document, the others see the change too.

Every call takes a list of pages, so one call works for a single page and for a multi-selection.

## Rotate pages

```ts
await pageEdit.rotateBy([page.ref], 90); // a quarter turn clockwise from where it is
await pageEdit.rotateBy([page.ref], -90); // and back
await pageEdit.setRotation([pageA.ref, pageB.ref], 180); // the same rotation for several
```

This rotates the page in the file. To only turn how pages are shown, use the Stage's
[view rotation](../viewing/stage#rotate-the-view). Keep the two on different buttons.

## Reorder pages

`move()` takes the pages and where they go:

```ts
await pageEdit.move([page.ref], { index: 0 }); // to the front
await pageEdit.move([page.ref], 'end'); // to the back
await pageEdit.move([pageA.ref, pageB.ref], { after: pageC.ref }); // after another page
await pageEdit.move([page.ref], { before: pageC.ref });
```

Several pages keep their order and land together.

## Delete pages

```ts
await pageEdit.delete([pageA.ref, pageB.ref]);
```

A document always keeps at least one page: deleting every page is refused.

## Insert pages

```ts
// A blank page after this one, the size of an A4 sheet
await pageEdit.insertBlank({ placement: { after: page.ref }, size: { width: 595, height: 842 } });

// Pages from another PDF: all of them, or the ones you name
await pageEdit.insertFromBytes(otherPdf, { placement: 'end' });
await pageEdit.insertFromBytes(otherPdf, { pageIndexes: [0, 2], placement: { index: 0 } });

// Pages from another document open in the viewer
await pageEdit.insertFromDocument(otherDocumentId, [pageRef], { placement: 'end' });

// Copies of pages, right after them
await pageEdit.duplicate([page.ref]);
```

Each resolves with `{ pages }`: the new pages, so you can scroll to them or select them. Without a
`size`, a blank page takes the size of the page before it.

## Extract pages

`extract()` gives you some pages as a new PDF, without changing this document:

```ts
const bytes = await pageEdit.extract([pageA.ref, pageB.ref]);
saveFile(bytes, 'chapter-2.pdf');
```

## Where a page goes

| Placement               | Means                         |
| :---------------------- | :---------------------------- |
| `{ index: n }`          | At position `n`, from 0       |
| `{ after: pageRef }`    | Right after that page         |
| `{ before: pageRef }`   | Right before that page        |
| `'end'`                 | After the last page           |

## Events

Page changes are document events, so every part of your app hears them, whichever plugin made the
change:

```ts
useDocumentsEvent(
  (documents) => documents.onPagesChanged,
  ({ pages }) => setPageCount(pages.length),
);
```

| Event            | Fires when                                  | Carries               |
| :--------------- | :------------------------------------------ | :-------------------- |
| `onPagesChanged` | Pages were added, removed, moved or rotated | `documentId`, `pages` |

## Permissions

| Permission          | What it allows                                                  | Check                  |
| :------------------ | :-------------------------------------------------------------- | :--------------------- |
| `doc.pages.assemble` | Rotate, reorder, delete and insert pages                       | `pageEdit.canEdit()`   |
| `doc.download`      | `extract()`, `duplicate()` and `insertFromDocument()`, which copy pages out | `pageEdit.canExtract()` |

## Good to know

### Pages have a ref, not just a number

Each page has a `ref`: its identity in the file. A page's index changes the moment a page before it
moves or goes; its ref never does. So a call still hits the page the user clicked, even if the
document changed in between. You get refs from `usePageList()` (`page.ref`), and anything that
points at a page carries one: a search result's `page`, an annotation's `page`.

### What moves with a page

Annotations, links and form fields belong to their page, so they move, rotate and go with it.
Rotation leaves annotations where they are on the page; they turn with it.
