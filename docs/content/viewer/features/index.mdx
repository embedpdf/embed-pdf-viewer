# All features

Most features are on from the start; measuring, redaction, building forms and snapshots wait until
you turn them on. Turn features on or off with `features`, by the name in the first column:

```js
{ features: { measurement: true, redaction: true, comments: false } }
```

| Feature | What people can do | On from the start | Settings |
| :-- | :-- | :-- | :-- |
| `annotations` | Highlight, underline and strike out text; draw; add notes, text boxes and callouts | yes | [Annotations](features/annotations) |
| `shapes` | Draw rectangles, circles, lines, arrows and polygons | yes | [Annotations](features/annotations#the-tools) |
| `comments` | Comment on annotations and reply, in a panel with every thread | yes | [Annotations](features/annotations#comments) |
| `stamps` | Place stamps: the standard ones, their own, or images | yes | [Annotations](features/annotations#stamps) |
| `signatures` | Draw, type or upload a signature; sign fields; check signatures | yes | [Forms & signatures](features/forms-and-signatures#signatures) |
| `forms` | Fill in forms; build them in the Form mode | Filling only | [Forms & signatures](features/forms-and-signatures) |
| `redaction` | Mark text and areas, then remove them from the file for good | no | [Annotations](features/annotations#redaction) |
| `measurement` | Measure distances, perimeters and areas at the drawing's scale | no | [Annotations](features/annotations#measurements) |
| `pages` | Rotate, move, insert, duplicate and delete pages in the thumbnails panel, each step undoable | yes | [Panels](customize/panels#organize-pages) |
| `attachments` | See, save, attach and remove files inside the PDF | yes | [Panels](customize/panels#the-attachments) |
| `search` | Find text, with every match highlighted and listed | yes | [`plugins.search`](/docs/headless/text/search#settings) |
| `text` | Select and copy text | yes | [`plugins.selection`](/docs/headless/text/selection#settings) |
| `snapshots` | Copy or save part of a page as a picture | no | [Documents](documents#take-a-snapshot) |
| `thumbnails` | A picture of every page, to jump around | yes | [Panels](customize/panels) |
| `outline` | The document's table of contents | yes | [Panels](customize/panels) |
| `documents` | Open other files (with the local engine), download, print, several documents in tabs | yes | [Documents](documents) |

## Turn features on and off

A feature that's off is gone everywhere at once: its buttons, its mode tab, its panel, its menu
rows and its shortcuts. Annotations already in the document still show; people just can't add new
ones. Most features have parts you can turn on or off on their own, such as `'forms.building'` or
`'documents.download'`.

`features` follows its prop, so a feature can come and go while the viewer runs, for example when
a user's plan changes.

[Turn features on and off](features/turning-off) has every feature and part, read-only, and what to
use when: `features` for what people can do, the layout for where a button goes, and the scope for
what a user may do.

## Each feature's settings

Every feature is a headless plugin, and `plugins` takes its settings by the plugin's name, exactly
as the plugin's page lists them:

```js
{
  plugins: {
    stage: { spread: 'odd', zoom: { mode: 'fit-width' } },
    search: { highlight: { color: '#a7f3d0' } },
    annotation: { tools: [{ id: 'highlight', defaults: { color: '#fde047' } }] },
  },
}
```

That opens documents as two-page spreads at the page's width, with green search matches and
yellow highlights. See [Plugins](code/plugins) for every plugin and how to change its settings
while the viewer runs.

## Good to know

### What loads when

A feature that's off is still in the viewer's code: `features` changes what people see, not what
you ship. The first load stays small another way. Each feature's panels and dialogs are files of
their own, which the viewer fetches in the background once the document shows, so they open at
once. The heavier parts wait until they're used: the signature checks until a signature is
checked, the standard stamps until Stamps opens, the handwriting fonts until someone types a
signature, and each language until it's chosen. [How it works](concepts/how-it-works#what-loads-when)
has the whole order.
